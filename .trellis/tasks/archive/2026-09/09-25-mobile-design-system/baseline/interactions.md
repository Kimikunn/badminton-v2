# 行为基线 — 逐屏交互清单（改版不得丢失）

> 截图同目录（-light/-dark 成对）。采集自测试环境 :8090，2026-09-25。
> e2e 行为回归以本清单为校对参考；e2e 已覆盖的部分以 e2e 为准。

## 首页 `/`
- 点击俱乐部卡片 → 原地内联编辑（名称/介绍，保存/取消）
- 赛季进度卡：当前赛季名 + 第 n/total 轮 + 进度条
- 进行中比赛（≤3 条，赛季/友谊）：点击 → `/scoring/:id` 记分
- 成员列表行：点击 → `/players/:id`；行尾显示已佩戴称号 pill
- 名人堂卡：点击冠军 → 该选手详情
- 组合冠军横幅：两个选手可分别点击 → 选手详情
- 趣味数据卡：绝对王者/不屈斗士 → 选手详情；最焦灼一局 → 比赛详情
- 赛季局数之最：点击 → `/rankings?season=<id>`

## 比赛 `/matches`
- 父级 tab：赛季比赛 / 友谊赛（状态跨页共享）
- 赛季 tabs：多赛季切换（selectedSeasonId）；测试模式下可删除
- 创建新一轮（进行中赛季）；历史轮次展开
- 比赛行 → `/matches/:id` 详情；进行中的比赛 → 记分入口
- 友谊赛 tab：新建友谊赛 + 对局列表

## 积分榜 `/rankings`
- 父级 tab：赛季积分 / 友谊赛
- 赛季 tabs 切换（联动 view accent 主题色）
- 各赛季规则页 S1-S6：页内 SegmentedControl 子视图切换（大分/小分等）
- 排名行 → 选手/比赛详情；支持 `?season=` 外部定位

## 场地 `/venues`
- 订场记录：列表 / 日历双视图（SegmentedControl）+ 设置按钮
- 记录行：显示头像/价格/备注；删除操作（ConfirmSheet 确认）
- 订场轮换卡：显示下一个轮值；"记录订场"主 CTA → 新建记录（Sheet 表单）
- 日历视图：切月、日期色条（监控/待放票）、点日期 → DaySheet 明细
- 场地信息 / 新增入口（页面底部）

## 比赛详情 `/matches/:id`
- 比分头（已结束/进行中状态 + 总比分 + 赛季名）
- 删除比赛（ConfirmSheet）
- 各局详情行：点击编辑（GameScoreInput）+ 删除
- 未满局数时新增下一局

## 选手详情 `/players/:id`
- 头像（可更换，上传）+ 称号墙 + 已佩戴称号设置
- 个人数据统计；比赛历史行 → 比赛详情

## 记分 `/scoring/:id`
- 实时比分 + 逐局记分输入（GameScoreInput）
- 结束局确认（EndGameConfirmSheet）；爆破局/抵抗局规则提示
- 全屏流程，无 TabBar
