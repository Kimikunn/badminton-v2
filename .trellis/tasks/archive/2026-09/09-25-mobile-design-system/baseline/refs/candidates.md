# 参考选型清单（待用户拍板）

> 规则：抄交互模式与信息层级，不抄品牌像素。选型结果回填
> `.trellis/spec/frontend/design-system.md` §7 表格。用户可自行浏览：
> - Mobbin（mobbin.com，筛 iOS + Sports/Health 分类，完整真实流程）
> - Appllama（appllama.io，按 home/standings/booking 屏型检索 5 万+ 真机截图）
> - Refero（refero.design，按 UI 模式分类）
> 用户也可以直接甩参考截图进对话。

## ① 首页（dashboard：俱乐部 + 赛季进度 + 进行中比赛 + 成员 + 荣誉墙 + 趣味数据）

- **A. Strava 式运动数据首页**：大数字统计（32-44px tabular 数字做视觉主角）+ 紧凑
  活动 feed。优点：数据感强、成熟克制；缺点：荣誉/称号表达弱，偏"记录工具"而非"俱乐部"。
- **B. Duolingo 式游戏化首页**：streak（连胜）卡、段位卡、荣誉展示用插画+彩色层级。
  优点：贴合项目"赛季/王/宝库/星尘"的游戏世界观，app 感最强；缺点：风格活泼，需要把控度。
- **C. Apple Fitness 式彩色 Hero + 数据环**：当前活动做彩色大区块 + 环形/进度视觉。
  优点：一屏一个锚点、iOS 原生感强；缺点：数据表达形式较单一。

## ② 比赛页（赛季/友谊双 tab，创建 + 历史记录）

- **A. Strava 活动 feed**：日期分组 header + 紧凑活动行（头像+标题+3 个指标）。
- **B. SofaScore 赛程页**：比分强调 + 状态徽章（live/已结束）+ 日期 section header。
- **C. Things 式事务分组**：按轮次分组、组头操作、主 CTA 固定位置创建。

## ③ 积分榜（S1-S6 规则各异 + 荣誉 + 宝库 + 星尘）

- **A. SofaScore/FotMob standings**：表格化、名次色带、粘性表头。优点：扫读效率最高。
- **B. op.gg/电竞战绩页**：分段位徽章 + 数据块 + 强调个人 KPI。
- **C. 卡牌图鉴/游戏仓库式**：荣誉与特殊规则（王之宝库、组合星尘）做成卡片图鉴，
  游戏感与世界观最贴；信息密度低时需要折叠技巧。

## ④ 场地页（订场记录 list/日历 + 轮换 + 缴费）

- **A. Airbnb 式日历预订**：日历为主视图，日期状态着色，选中 → 底部摘要条。
- **B. 记账类记录列表**：日期分组 + 行内摘要 + 顶部汇总条。
- **C. 停车缴费类（捷停车/首程）**：大 CTA + 记录流，与"轮换+缴费"流程最接近。

## ⑤ 详情页（比赛详情 / 选手详情）

- **A. Apple Music 专辑页式**：顶部大摘要 hero + 下方分区卡片。
- **B. op.gg 对局时间线**：紧凑行 + 左侧局号时间轴，一屏多局。
