# 订场日历 v3：固定单月自绘 + 色条/填色统一视觉

## Goal

替换测试环境现行的 Vant Calendar 版订场日历（`BookingCalendar.vue`）：骨架改为**自绘固定单月 + ‹›箭头切月**，视觉语言收敛为**「监控=底部多段色条、今天/订场记录/不可用=格子填色」**两种手段。定稿依据：本任务 `research/mockup-v3.html`（经用户逐轮确认定稿）+ ADR 0003。

## Background

- 生产（:8088）仍是 9-18 旧版自研网格（用户不满意但不动它）；测试（:8090）是 9-23 的 Vant 版（用户不满意）。本任务以测试环境现行 Vant 版为基础继续改，完成后随下次发版覆盖生产。
- 用户痛点（原话归纳）：① 设计元素不统一（有方格有圈），参考苹果日历用颜色/点线表达；② 骨架交互不行（月份滚动、高度、选中态残留）。

## Requirements

- **R1 骨架**：自绘固定单月月网格，一次只渲染一个月；`‹›` 箭头切月，不支持横滑。首屏=今天所在月。未来上限=今天所在月 +6 个月；过去下限=**最早订场记录所在月**（订场记录回看；到边禁用箭头）。
- **R2 数字对齐**：日期数字永远几何居中；色条绝对定位贴底、休/班绝对定位右上，任何标记组合不改变数字位置。
- **R3 监控色条**：每条监控一根 4px 色条、贴底并排（多段拼接，最多 3 段，再多折叠为 `+N` 样式或直接截断——实现时按草图现状最多全显）。配色沿用 `MONITOR_BADGE_VARIANT` 变体语义：需验证=warning 黄、已锁到=success 绿、监控中=accent 蓝、待放票/等待放票=badge-blue 靛蓝（两态共色）。**已暂停不显示条**；**已过期（过去日）无条**且整格淡化（opacity .35）；**不可用日不显示监控条**。
- **R4 填色语言**：今天=实心 accent 蓝底+反白数字；订场记录=success 绿淡底（未来）/淡绿（过去，跟随过去日淡化）；今天+订场记录共存时今天蓝底优先；不可用=danger 红淡底+数字划线。
- **R5 休/班**：数字右上角 8px 小字（休=danger 红、班=fg-muted 灰），沿用 `HOLIDAY_TYPE_MARKS` 字形语义；**月节日摘要整行删除**（`monthHolidaySummary`、可见月 IntersectionObserver 跟踪一并删除）；节日名只在 DaySheet 看。
- **R6 底部信息栏**：色条语义图例 + 填色图例（项随当月实际出现的语义动态出现）+ 当月总时长（`12h` 右对齐，沿用现有计算）。
- **R7 交互**：点今天及以后某天 → 打开 DaySheet（含不可用日，可在里面取消标记）；过去日不可点。
- **R8 复用**（用户明确要求）：不新增色值——色条颜色走 variant→CSS 变量映射；`metaByKey` 日期领域信息结构保留；`DaySheet` 不动；`data-date` e2e 锚点模式保留；深色模式沿用现有 token（`.dark` 变体）。

## Requirements（补充，2026-09-23 第二轮：列表回生产版 + 视图切换右上角）

- **R9 列表结构回生产版**（:8088 现行 9-18 构建的订场记录卡结构）：移除 Vant Tabs；列表装进与日历**同高的容器**（见 R13），超出内部滚动；无记录时 EmptyState（日历仍是监控唯一入口，可切换）。
- **R10 切换器右上角**：标题行右侧放 `SegmentedControl`（列表/日历，size sm）+ 监控设置齿轮钮（生产版同位）；标题左对齐同一行。
- **R11 订场记录卡片整体协调**：间距/宽度打磨——标题行 mb、行内边距、日历与卡片左右边缘对齐、日历信息栏与网格左缘对齐；360/390 宽度下不折行不溢出。
- **R13（2026-09-23 第三轮）两视图等高**：日历网格**固定渲染 6 行**（不足的月份用隐形格子补齐，日历自身高度恒定，切月不变高）；列表与日历共用同一固定高度容器（高度=日历自然高度），列表超出内部滚动——**切换 Tab 时订场记录卡片高度不变**。
- **R14（2026-09-23 第五轮修订）一键全部展开**：列表初始预览**填满容器**（默认 5 条会在 424px 容器下留 ~127px 空白，实测截图确认；初始条数按行高计算 = floor((容器高 − 按钮高)/行高) ≈ 7 行，静态值+换算注释）；「展开全部（共 N 条）」按钮**一次点击打开全部**（恢复一键展开，废弃第三轮的 +10 增量）；已全部打开后按钮变「收起」，点击回到初始预览并滚回列表顶部。
- **R15（第四轮→并入 R14）**：收起能力保留（回到初始预览行数 + 滚回顶部），与「展开全部」同一按钮位置切换。
- **R16（第四轮）相邻月日期填充**：日历不再用隐形格补行——网格首行空位用**上月日期**、尾部空位用**下月日期**填充（Apple 日历做法），呈现为过去日同款淡化灰（opacity .35、无 data-date、不可点、无任何领域标记）；相邻月日期可能超出可浏览范围（如 +6 月的最后一天），只做视觉填充不带数据。日历恒 6 行、高度恒定的既有契约（R13）不变。
- **R14/R15/R17（2026-09-23 第七轮最终收敛，取代前两轮的展开/收起机制）**：**取消「展开全部/收起」机制**——列表默认全量展示所有记录，装在与日历等高的固定容器内滚动（overflow-y auto 常开）；无预览条数、无按钮，也就无遮挡与预览态禁滚的边界问题。吸底按钮条随之删除。
- **R12 依赖收敛**：Vant 全项目不再被引用后从 `client/package.json` 移除 `vant`。
- e2e 适配：`holidays.spec.js` 里 `getByRole('tab')` 改 SegmentedControl 按钮选择器。

## Constraints

- 纯前端：`client/src/components/venue/BookingCalendar.vue` + `client/src/stores/intent.js`（聚合函数）+ `client/src/views/VenueView.vue`（接线）；不改订场/监控/推送逻辑、不改服务端。
- 移除 Vant Calendar 依赖引用（`vant` 的 Calendar 组件与样式 import）；`vant` 包本身若 Tabs 等仍在用则保留依赖。

## Acceptance Criteria

- [ ] **AC1**（e2e）固定单月：默认渲染今天所在月；点 `›` 到下月、`‹` 回上月；到达最早订场记录月时 `‹` disabled，到达 +6 月时 `›` disabled。
- [ ] **AC2**（e2e，固定时钟 2026-10-01）十月格子：10-01 显示「休」右上小字；10-10 显示「班」；普通日无标记。
- [ ] **AC3**（e2e）监控色条：某天两条监控 → 两段并排色条（data-date 锚点定位）；已暂停日无色条；不可用日无色条。
- [ ] **AC4**（e2e）填色：今天格子有蓝底类；有订场记录的未来日绿底类、过去日淡绿；不可用日红底+划线类。
