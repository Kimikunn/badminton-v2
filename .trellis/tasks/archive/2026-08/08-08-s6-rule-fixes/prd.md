# S6 规则修正：月白抵抗局与逐人暗选

## 背景

S6 三切片已交付（archive/2026-08/08-07-s6-season，commit e3e5e88/34496b1/e992451）。用户验收后提出两处规则理解修正。

## 需求

### R1 月白 = 抵抗局（类比 S5 秩序）
- 规则原文：月白——只有对方先到达 15 分时才获得"抵抗"（赛点球对方必须连拿 2 分）
- 用户确认：月白局**可能出现分低者获胜**，与 S5 秩序（resistance）同模型
- 实现：王选形态为 yuebai 时，王参与的比赛的局按抵抗局处理——`scoringMode:'resistance', targetScore:21, maxScore:30, requiresWinner:true`，局终显式选择胜方（复用 S5 的校验与记分页胜方选择 UI）
- 简化决策：不再追踪"对方是否先到 15 分"这一局中事件——抵抗校验是标准 21 分制的超集（正常获胜比分同样合法），王的所有月白局一律按抵抗局配置；记分页提示保留

### R2 暗选逐人提交
- 原实现：每方（组合）一条暗选记录，双方提交后亮出
- 修正：**4 名选手各自决定本人的技能是否使用**，各自提交（选本人拥有的一张局前卡或"不使用"），4 人全部提交后同时亮出
- 卡片归属：选手只能启用**本人在灵魂契合中选到的卡**（`soulBond[*][*].picks` 的 playerId 归属）；库存仍按组合扣减
- `s6_card_activate` payload 增加 `playerId`，服务端校验选手属于该方组合且拥有该卡；每人每局至多一条暗选
- 亮出条件：该局 4 人均已提交 → 全部 `revealed: true`
- 效果应用：激活记录仍带 `side`（由选手归属推导），结算逻辑（阻碍/进击/星尘卡按 side 生效）不变；同一方两名选手可各激活一张
- 记分页暗选 UI：由"每方一条"改为"4 名选手各一条"（显示选手名 + 已暗选/卡名）

## 验收标准

- A1：月白局记分页要求显式选择胜方；分低者获胜（如 21:29 胜方为 21 分侧）服务端校验通过；普通比分（21:15）同样可结束
- A2：非月白的上篇局行为不变；绯红/黛青不受影响
- A3：暗选必须 4 人各自提交才亮出；选手不能使用未选到的卡（422）；同一人同局重复提交拒绝
- A4：同一方两人各激活一卡时两个效果都正确生效（如一人爆破一人星尘卡）
- A5：已有 e2e 规格适配新模型后全绿；`server npm test` 全绿；`client npm run build` 通过
