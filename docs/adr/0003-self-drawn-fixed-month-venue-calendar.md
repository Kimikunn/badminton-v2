# 订场日历弃用 Vant Calendar，改自绘固定单月网格

2026-09-23 上午刚完成「自研网格 → Vant 4 Calendar 包装」的重构（任务 09-23-venue-calendar-vant），当天用户试用后否决：垂直连续滚动月历的骨架交互（月份滑动不确定、高度失控）与格子上「胶囊/徽标/圆点/角标/色环」五种形状混排的视觉语言都不满意。经草图迭代（固定单月 + 箭头切月、监控=底部多段色条、今天/订场记录/不可用=格子填色）定稿后，决定**弃用 Vant Calendar，改为自绘固定单月网格**：一次只渲染一个月、格子尺寸固定、`‹›` 箭头切月、无横滑手势。自绘成本可控，因为 Vant 只提供了骨架，领域标记本来就全部是自定义插槽；同时可一并删掉为「可见月摘要」服务的 IntersectionObserver 跟踪和 `monthHolidaySummary`。

## Considered Options

- **保留 Vant 滚动月历，只修标记排版**：骨架交互本身被否决（用户明确选择固定单月），且 Vant 逐月渲染高度不可控，否决。
- **自绘但支持横滑切月**：与外层页面纵向滚动手势有冲突风险，且用户确认只要箭头，否决。

## Consequences

- 日历徽标契约从「折叠为优先级最高一条 + 条数角标」改为「每条监控一段色条并排」（见 CONTEXT.md 监控状态）。
- Vant Calendar 依赖与样式覆盖（`--van-calendar-*` 变量映射）移除；e2e 的 `.van-calendar__day` 选择器需改自绘网格选择器，`data-date` 锚点模式保留。
- 可浏览范围：未来 +6 个月（监控窗口），过去回翻到最早订场记录所在月（订场记录回看语义进入日历）。
